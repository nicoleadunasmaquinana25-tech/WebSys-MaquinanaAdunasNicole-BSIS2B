## Weekly Summary

Week 1 - HTML Fundamentals
Created the basic structure of a webpage using HTML elements, headings, paragraphs, links, images, and lists.
Week 2 - Semantic & Multimedia
Used semantic HTML elements such as header, nav, main, and footer, and added multimedia content like audio and video.
Week 3 - CSS Basics
Styled webpages using CSS properties for colors, fonts, spacing, borders, and layouts to improve the overall appearance.
Week 4 - JavaScript Basics and DOM Manipulation
Implemented JavaScript variables, data types, operators, and event handling to make webpages interactive through DOM manipulation.
Week 5 - JavaScript Functions and Bootstrap
Created reusable JavaScript functions and used Bootstrap components and responsive grid layouts to build user-friendly webpages.
Week 6 - API & Client Storage
Integrated APIs to retrieve and display data dynamically and used local storage or session storage to save data on the client side.
Week 7 - MiniFullStackStarter
Developed a mini full-stack application by combining frontend technologies with backend functionality to handle data and demonstrate basic full-stack development.
